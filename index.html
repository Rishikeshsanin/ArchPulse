PROJECT ARCHITECTURE

Native core. Browser companion.

01

C++ Simulation Core

Set-associative cache modeling, LRU eviction, five-stage pipeline behavior, hazard accounting, CPI/IPC and branch predictors.

02

Parallel Benchmark Engine

Custom thread pool using threads, mutexes, condition variables and futures for matrix, convolution and scaling studies.

03

Analytics Pipeline

Structured CSV output feeds Python, Pandas and Matplotlib reports for cache, pipeline and thread-scaling experiments.

04

Cross-Platform CI

CMake and CTest build and validate ArchPulse on Linux and Windows through GitHub Actions.
